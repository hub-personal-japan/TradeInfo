# DAYTRADE ダッシュボード(GitHub Pages 版)

日本株デイトレ用。**情報タブ**(全上場銘柄のスキャナー・市場状態・ニュース)と**収支タブ**(約定履歴CSV/手入力→成績・日誌)。
サーバーやbatは不要。GitHub Actions がデータを取得して GitHub Pages で公開します。AIはAPIを使わず、プロンプトを作って ChatGPT / Claude を画面の右側に開きます。

> **最初に `はじめにお読みください.md` を読んでください。** Cloudflare Worker の差し替えから公開までを、画面操作の順に説明しています。あなたのWorker URL(https://tradeinfo.yusuke1028-jpn.workers.dev)はサイトに初期設定済みです。

## 公開手順(最初の1回)
1. GitHub で新しいリポジトリを作成(Public 推奨)。
2. この zip を**解凍して、中身を全部**アップロード(`.github` フォルダを含める。`daytrade-github` フォルダごと入れない)。
3. Settings → Pages → Source を **GitHub Actions** にする。
4. Actions タブ → `update-site` → Run workflow。数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` が開きます。

## 更新の速さについて(正直な説明)
| 層 | 仕組み | 遅れ |
|---|---|---|
| ① 全銘柄 | Actions が約12分ごとに全上場銘柄の日足を取得 | 最大約12〜17分 |
| ② 注目銘柄 | Actions が**5分ごと**に注目約150銘柄の1分足だけ更新(高速モード) | 約5〜8分 |
| ③ ライブ(注目) | ブラウザが**5秒ごと**に、選択中・★・熱さ上位25銘柄・主要指数の1分足をWorker経由で取得 | 数秒 |
| ④ ライブ(全銘柄) | ブラウザが**60秒ごと**に、**全銘柄(約3,900)**の現在値・出来高をWorker経由でスキャン(約87リクエスト) | 約1分 |

- **株価の元データ(Yahoo!ファイナンス)自体が約20分遅れ**です(東証の無料配信の仕様)。これは③でも超えられません。③は「当サイト側の遅れ」をほぼゼロにするためのものです。本当のリアルタイムは、証券会社のツール・API(SBI HYPER、立花証券 e支店API など)が必要です。
- ブラウザは通常 Yahoo に直接つなげない(CORS)ため、③は次の順で自動的に試します: 直接 → **自分のCloudflare Worker** → 公開プロキシ。画面上部の「ライブ:」ボタンを押すと、各経路の診断と設定ができます。
- **おすすめ: Cloudflare Worker(無料・約5分)**: `worker/yahoo-proxy.js` を Cloudflare の Worker に貼り付けて Deploy → 表示されたURLを「ライブ」ボタンの画面に貼り付けて保存。1回の通信で最大45銘柄をまとめて取得します(無料枠で足ります)。
- Actions の定期実行は GitHub 側の都合で遅れたり飛んだりします(最短5分)。

## 全銘柄が出ないとき / 英語になるとき
JPX が公開している「東証上場銘柄一覧」は現在 **`data_j.xlsx`**(以前は `.xls`)です。スクリプトは xlsx/xls/CSV に対応し、固定URLが変わった場合は JPX のページからリンクを探します。それでも取れない場合は、
1. JPX の「東証上場銘柄一覧」Excel を手元でダウンロードし、CSV(UTF-8)で保存して、リポジトリ直下に `universe.csv` として置く(最優先で使われます)。
2. それも無い場合は、証券コード1301〜9999を総当たりで探索します(英語名・業種「未分類」になります)。

## 画面
- 上部: 時計・状態・株価時刻とデータの古さ・ライブ接続・更新間隔(5秒〜)。ティッカーに指数・先物差・SOX・VIX・判定・主戦場・「今の時間帯/今日の相場での自分の成績」。
- **情報タブ**: 左=市場状態・指数・セクター・今日の予定(あと○分)・★ウォッチ・アラート / 中央=スキャナー(11種の表示 + 業種・市場・株価・前日比・出来高倍率・GAP・熱さ・★・ニュースで絞込 + 全銘柄検索)とニュース / 右=AI。銘柄クリックで右からドロワー(熱さ内訳・価格の位置関係・OR・ニュース・同業)。
- **あなたの実績**: スキャナーの各銘柄に、収支タブの取引データから「この銘柄/業種での自分の勝率・平均損益」を表示します(Kabutanなどに無い、このサイト独自の見方です)。
- **アラート**: ★・選択中の銘柄で、VWAP抜け・ORブレイク・当日高値更新・5分急変・出来高急増を表示(音は任意。ライブ取得が必要)。
- **収支タブ**: 常に最新日を既定表示。日別・銘柄別・時間帯・曜日・市場環境・セクター・セットアップ別、トレード日誌、バックアップの保存/読込。
- 表示の大きさ: 各項目の右下をドラッグして高さを変更、列の境目をドラッグして幅を変更(自動保存)。ヘッダーの「表示の大きさを初期化」で戻せます。
- 画面を更新しても、前回のデータ・選択銘柄・絞込条件・収支データが残ります(ブラウザ内に保存)。

## その他の制限
- 株価は Yahoo!ファイナンスの非公式APIです。仕様変更・アクセス制限で止まる可能性があります。
- 全銘柄の分足指標(VWAP等)は注目約150銘柄と、ライブ取得した銘柄のみです。
- 板情報・特別気配・大口約定・信用残・空売り・時価総額は未対応(無料のデータ元がありません)。予定(CPI/FOMC/日銀/決算)は `events.json` に `[{"date":"2026-10-30","time":"12:00","name":"日銀会合"}]` の形式で追記。
- 公開リポジトリは60日間更新がないと定期実行が止まります。
- 表示は情報提供であり、売買の推奨ではありません。
