# DAYTRADE ダッシュボード(GitHub Pages 版)

日本株デイトレ用。**情報タブ**(全上場銘柄の市場情報・ランキング)と**収支タブ**(約定履歴CSV/手入力→成績・日誌)の2画面。
bat/サーバーは不要で、GitHub Actions が定期的にデータを取得し、GitHub Pages で公開します。AIはAPIを使わず、プロンプトを作って ChatGPT / Claude を画面の横に開きます。

## 公開手順(最初の1回)
1. GitHub で新しいリポジトリを作成(Public 推奨。Private で Pages を使うには有料プランが必要な場合があります)。
2. このフォルダの中身を**そのまま**アップロード(`.github` フォルダを含めること)。
3. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
4. **Actions** タブ → `update-site` → **Run workflow**。数分後に公開URL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)が使えます。
5. 以降は平日の場中に約15分ごとに自動更新されます(`.github/workflows/update.yml` で変更可)。

## 画面構成(PC向けの端末風・中央だけスクロール)
- 上部: 時計・更新・市場状態(1行)と、日経/TOPIX/グロース/ドル円/先物差/SOX/VIX/判定/主戦場のティッカー。
- **情報タブ**: 左=市場状態(日本株指数・外部環境・値上がり比率・VIXの0〜100)・指数・セクター・今日の予定(「あと○分」)・★WATCH / 中央=スキャナー(熱さ・急騰・急落・出来高・GAP上下・VWAP上下・相対強度・異常検知・売買代金、全銘柄の検索)とニュース / 右=AI(固定)。銘柄をクリックすると右からドロワーが開き、熱さの内訳・価格の位置関係(高い順)・オープニングレンジ・ニュース・同業銘柄が出ます。
- **収支タブ**: 損益サマリー、SESSION STATUS(連敗と過去データ)、日別・銘柄別・時間帯・曜日・市場環境・セクター・セットアップ別の成績、トレード一覧と日誌。手入力は折りたたみの中。
- 熱さスコア(0〜100)= 値動き25 + 出来高倍率25 + 寄付GAP15 + 売買代金15 + VWAP乖離10 + ニュース件数10。内訳は必ず表示されます。売買シグナルではなく、候補を絞るための目安です。
- 画面が狭いとき(分割表示など)は、列が縦並びになり、表はカード表示に切り替わって、情報は隠れません。

## 全銘柄が出ないとき
1. Actions のログに「JPX銘柄一覧: N銘柄」と出ていれば正常です。
2. 「JPX銘柄一覧の取得に失敗」と出た場合、自動で証券コード1301〜9999を総当たりで探索します(初回は時間がかかります。業種は「未分類」、英数字コードの新しい銘柄は漏れます)。見つかった一覧は Actions のキャッシュに保存され、次回以降に使われます。
3. 画面上部に「全銘柄の一覧を取得できていません」と出ている間は、銘柄数が少ない状態です。`scripts/fetch_data.py` の `JPX` のURLを、JPXの公開ページにある最新の「東証上場銘柄一覧」ExcelのURLに直してください。

## 使い方
- **情報タブ**: 市場全体(日経・TOPIX・グロース・先物・為替・米株・SOX・VIX・金利・原油・金・上海・ハンセン)、市場の方向、今日の予定、9種のランキング、注目銘柄(熱さ上位20)、銘柄詳細(VWAP・1/5/15分・重要価格・値幅消化)、同業銘柄、セクター、ニュース(時刻つき)、★ウォッチ、**全銘柄一覧(検索・業種/市場絞込・並替)**。
- **収支タブ**: SBI証券の約定履歴CSV取込(再取込しても重複しない)、手入力、FIFOでトレード単位に集計、時間帯別/日別/月別/曜日別/銘柄別、期間比較、税引後(概算 20.315%)と資産額、トレード日誌(損切りライン・買い/売りの理由・気持ち)。参考: ari-mama.com のトレード日誌テンプレート。
- **AI**: 下部の「AIプロンプト」で種類を選び、「ChatGPTを横に開く」「Claudeを横に開く」。プロンプトは自動でコピーされるので貼り付けるだけ。AIの画面は右側の別ウィンドウに開き、この画面は左58%の「分割表示」に自動で切り替わります(幅が狭くなると、情報は縦並び・折り返しに変わり、隠れません)。ChatGPT/Claude は仕様上、他サイトへの埋め込み(iframe)ができないため、別ウィンドウ方式です。

## 重要な制限(必ずお読みください)
- **リアルタイムではありません。** GitHub Actions の定期実行は最短でも約15分間隔で、混雑時は遅れます。Yahoo!ファイナンス側にも最大20分程度の遅延があります。
- 株価は Yahoo!ファイナンスの**非公式API**です。仕様変更・アクセス制限(特にGitHubのIPからの大量取得)で止まる可能性があります。全銘柄の取得が一部失敗しても、取れた銘柄だけで更新します(失敗が多すぎる場合は更新を中止し、前回の公開が残ります)。
- 全銘柄の分足(VWAP等)は取得量の都合で**熱い上位約100銘柄のみ**です。★登録した銘柄と選択中の銘柄は、ブラウザから直接取得(**試験的**)して補完します。ブラウザ制限で失敗する場合は自動で停止し、画面上部に表示されます。
- 銘柄一覧は JPX 公開の「東証上場銘柄一覧(data_j.xls)」から取得します。**このURLは作成時に動作確認できていません。** 取得に失敗した場合は `data/universe.json`(10銘柄のサンプル)にフォールバックします。Actions のログに「JPX銘柄一覧の取得に失敗」と出たら、JPXの公開ページで最新のExcelのURLを確認して `scripts/fetch_data.py` の `JPX` を直してください。
- 公開リポジトリでは、60日間リポジトリの更新がないと定期実行が自動で止まります(Actions タブで再有効化)。
- 板情報・特別気配・大口約定・信用残・空売り・時価総額は未対応(無料のデータ元がないため)。CPI/FOMC/日銀会合/決算などの予定は `events.json` に `[{"date":"2026-10-30","time":"12:00","name":"日銀会合"}]` の形式で追記してください。
- 収支データ・日誌・★はブラウザ内(localStorage)にのみ保存され、リポジトリには送られません。別のブラウザ/PCとは共有されません。
- 表示は情報提供のみです。売買の推奨ではありません。
